# DX12 Town — 影 / GI / レイトレ 統合実装マスタープラン

作成: 2026-07-12。目的: CSM の限界（ちらつき・カスケード出没）を脱し、**UE5 相当**の
「自然な動的影＋間接光（GI）＋反射」を、段階的・低リスクに実装するための設計とステップ表。

---

## 0. 役割分担（UE5 と同じ思想）

| 領域 | 技術 | 理由 |
|---|---|---|
| **影（太陽＋多数ローカルライト＋ボリューメトリック）** | **VSM (Virtual Shadow Maps)** | 1系統で全影を統一。per-pixel 解像度でちらつき/継ぎ目ゼロ。ボリューメトリックは**マップ参照**で安い。UE5 の `r.Shadow.Virtual.Enable=1` と一致 |
| **拡散間接光（多重バウンス・カラーブリード）** | **DDGI**（レイトレ・イラディアンスプローブ, DXR）| Lumen 拡散GI の実用的再現。TLAS 再利用 |
| **鏡面間接光（光沢反射）** | **RT 反射**（DXR）| Lumen 反射相当。既存 `RayTracingManager` 反射を全光沢面へ拡張 |
| 環境光ベース | IBL キューブ（既存）| DDGI 未整備領域のフォールバック |

**DXR は「影」ではなく「間接光/反射」に使う**（RTの得意分野）。影は VSM。＝UE5 の分担そのもの。

## 2. 共有の前処理（全トラックの前提）

### F1. 町ジオメトリを DXR TLAS へ (前提: DDGI・RT反射)
- **目的**: DDGI とRT反射が参照する加速構造に町を載せる。
- **実装**: `TownScene::Init` 後、`m_cache` の各 `TownModel` submesh を `RayTracingManager::AddBLAS`（頂点/インデックスは既に DEFAULT ヒープ VRAM）。町は**静的**なので BLAS は 1 回構築。TLAS は町インスタンス transform から `BuildTLAS`（静的なら 1 回 + 動的葉のみ更新）。
- **統合点**: `Scene.cpp` の RT 初期化に町登録を追加。`RTInstance.blasIndex` を submesh ごとに保持。
- **バインドレス紐付け**: `D3D12_RAYTRACING_INSTANCE_DESC.InstanceID` に **submesh のマテリアル index** を入れ、ヒットシェーダが `BindlessMaterial` を引けるように。
- **検証**: RT デバッグパス（TLAS に対し1次レイ→ヒット距離/法線を可視化）。
- **工数** 3〜5日 / **リスク** 低（API 実績あり）

### F2. 薄い G-Buffer（前提: RT反射, DDGI の一部）
- フォワードなので反射/GI の**画面側**に法線・ラフネスが要る。HDR RT の隣に **RG16F 法線 + R8 ラフネス**の薄い MRT を追加（or 既存 HDR の alpha に反射率をパック）。
- **工数** 2〜3日 / **リスク** 低〜中（町PSに SV_Target1 追加、PSO の RTV 数）

## 3. トラック S：影 = VSM（最重要・最大）

> クリップマップ（太陽）＋ページアトラス（ローカルライト）を、**可視ページだけ**描画・キャッシュする。

### S0.（任意・当座しのぎ）clipmap-lite
VSM 本実装まで時間がかかるため、当座 CSM のちらつきを構造的に減らす中間策。
3〜4 レベルの**カメラ中心・ワールド整列**シャドウマップ（回転不変）、per-pixel レベル選択。
- **工数** 3〜5日 / **リスク** 中 / VSM 完成で破棄。要否は判断。

### S1. VSM スケルトン（太陽・非キャッシュ・全描画）
- **データ構造**:
  - **物理ページプール**: 1 枚の大きな深度アトラス（例 8K×8K = 128×128 タイル, 各 128²）。
  - **仮想アドレス空間**: クリップマップ N レベル（例 16 レベル, 各 16K² 仮想）。
  - **ページテーブル** (StructuredBuffer): 仮想ページ→物理タイル index（未割当=∞）。
- **パス**: (a) 使用ページを全マーク（暫定＝全部）→(b) 物理タイル割当→(c) 割当ページへ影キャスタを描画→(d) サンプル時に仮想→物理変換。
- **サンプラ**: `TownShadow.hlsli` の `SampleSunShadowSoft` を **VSM 参照**に差し替え（worldPos→クリップマップレベル選択→仮想UV→ページテーブル→物理UV→深度比較）。
- **検証**: 静止で CSM と同等の影。ページ境界の破綻無し。
- **工数** 1.5〜2週 / **リスク** 高（アドレス変換・アトラス管理）

### S2. 深度からのページマーキング（性能の要）
- **目的**: 画面に見えるページだけ割当・描画。
- **実装**: シーン深度（or HZB）を走査する CS。各ピクセルの worldPos→必要クリップマップレベル（カメラ距離）→仮想ページ→ページテーブルに「要求」マーク。マークされたページのみ S1(c) で描画。
- **統合点**: `HiZSystem` の HZB を流用。
- **工数** 4〜6日 / **リスク** 中

### S3. ページキャッシュ（静的シーンで劇的に軽く）
- **目的**: 静的ジオメトリのページはフレーム跨ぎで保持、無効時のみ再描画。
- **実装**: ページに「有効」フラグ。太陽方向変化・ジオメトリ変化・レベル中心移動で該当ページ無効化。町は静的 → ウォームアップ後ほぼ再描画ゼロ。
- **工数** 4〜6日 / **リスク** 中（無効化の正しさ）

### S4. ローカルライト影（多数の街灯・スポット）
- **目的**: 大量ライトの影を同じアトラスで。
- **実装**: `ClusterGrid` のライトリストから、各ライトの VSM（スポット=1枚、点=6面 or パラボラ）を同じページアトラスに割当。ページマークはクラスタ可視性から。
- **統合点**: `ClusterLightAssign_CS` / `ClusterShading.hlsli` にシャドウ項を追加。
- **工数** 1〜1.5週 / **リスク** 中〜高

### S5. ソフト影フィルタ
- SMRT（screen-space ray-marched，UE5式）or 仮想空間 PCF。太陽視直径 0.5° に合わせた可変ペナンブラ（接触は硬く遠くは柔らかい）。
- **工数** 3〜5日 / **リスク** 中

### S6. ボリューメトリック統合
- `Volumetric_CS.hlsl` の各フロクセルで VSM をサンプル → フォグ内の光条（god rays）。**RTより桁違いに安い**のがVSM採用の主目的の一つ。
- **工数** 3〜5日 / **リスク** 低〜中

**トラックS 合計: 約 4〜7 週**

## 4. トラック G：拡散GI = DDGI（DXR）

> ワールドに配置したイラディアンスプローブを毎フレーム TLAS でレイトレし、多重バウンス拡散光を供給。

### G0.（任意・独立の早期勝ち）GTAO
- スクリーン空間 AO（DXR 不要）。接地感が即上がる。A4 の平坦アンビエントを締める。
- **工数** 2〜3日 / **リスク** 低

### G1. プローブボリューム土台
- **配置**: 歩行域を覆う3Dグリッド（間隔 2〜4m）。複数ボリュームでLOD可。
- **バッファ**: プローブ毎に **八面体マップ** irradiance（例 8²/プローブ）＋ 可視性(depth/Chebyshev) アトラス。
- **工数** 3〜4日 / **リスク** 低

### G2. プローブ・レイトレ更新（DXR, 前提 F1）
- 各プローブから TLAS へ N レイ（64〜256, ブルーノイズ回転）。**ClosestHit** で `BindlessMaterial` から材質→`アルベド×直接光(VSM影付き) + 前フレームのプローブirradiance(多重バウンス) + emissive`。Miss=空(IBL)。
- 結果を八面体に集積。
- **工数** 4〜6日 / **リスク** 中（ヒット着色・バインドレス）

### G3. 時間ブレンド＋八面体エンコード
- 前フレームと指数移動平均（ヒステリシス）。境界パディング。
- **工数** 2〜3日 / **リスク** 低

### G4. シェーディング統合（A4 置換）
- `TownPS.hlsl` の A4 ambient（line 305-308 付近）を **周囲8プローブの可視性重み付きトライリニア補間**に置換。拡散間接光＋カラーブリード。
- **工数** 2〜3日 / **リスク** 中（リーク対策 = 可視性重み）

### G5. 多重バウンス
- プローブが前フレームのプローブ irradiance を取り込む（G2 に内包）。収束させる。
- **工数** 1〜2日 / **リスク** 低

**トラックG 合計: 約 1.5〜2.5 週**

---

## 5. トラック R：鏡面GI = RT 反射（DXR）

### R1. RT反射を全光沢面へ（前提 F1, F2）
- 既存 `RayTracingManager::DispatchWaterReflection`（半解像度）を、**G-Buffer 法線/ラフネスを使う汎用反射**へ拡張。反射レイ→ClosestHit で `直接光(VSM) + DDGI irradiance` を着色。ラフネスでレイ発散（GGX 重要度）。
- **工数** 5〜7日 / **リスク** 中

### R2. デノイズ＋アップスケール＋統合
- 半解像度の時空間デノイズ（`Temporal_CS` 流用可）→ フル解像度へ。TownPS のガラス/濡れ反射（C1）を RT 反射に差し替え（ヒット時）、ミスは prefilter キューブ。
- **工数** 3〜5日 / **リスク** 中

**トラックR 合計: 約 1.5〜2 週**

## 8. 検証戦略
- 各マイルストーンで `DX12_CAPTURE` キャプチャ＋ PIX/RenderDoc。
- **影**: ①静止で正しい ②カメラ回転/移動でちらつき無し（VSM per-pixel）③接触に peter-panning 無し。
- **GI**: 赤い壁の隣の地面が赤く染まる（カラーブリード）、影の中が真っ黒でなく間接光で持ち上がる。
- **反射**: 濡れ面/ガラスが実ジオメトリを映す、ラフネスでボケる。
- **性能**: 各パスの GPU 時間を Profiler で計測。VSM ページ数・DDGI レイ数・RT反射解像度で調整。

## 9. フォールバック / 非対応GPU
- DXR 非対応（`DXR=NO`）: DDGI/RT反射を無効化し **IBL + GTAO** に自動フォールバック。
- VSM 重い環境: クリップマップレベル数・ページ解像度を下げる。最悪 CSM（現行）に戻せるよう `ShadowSystem` は残す。

## 12. VSM 本体（仮想ページ化）詳細ステップ表 ★次の大工事（複数セッション）

> 目的: カメラ中心クリップマップ(Step1)の上に**仮想ページ＋物理プール**を載せ、**画素毎解像度**を得て
> 細部エイリアスを根絶。新規 `Source/Graphics/VsmSystem.{h,cpp}` + `Shaders/Vsm/*`。

### アーキテクチャ
- **仮想空間**: クリップマップ K レベル（例8）。各レベル L×L 仮想テクセル（例 8192²）。カメラ中心、レベル i は 2^i×base の世界範囲を覆う（=Step1のクリップマップを多重解像度化）。
- **物理プール**: 1枚の深度アトラス（例 8192² D32, `ALLOW_DEPTH_STENCIL`）を 128² ページに分割（=4096枚）。空きページのフリーリスト。
- **ページテーブル**: 仮想ページ→物理ページindex（無効=0xFFFF）。`StructuredBuffer<uint>`、全レベルの仮想ページ数分。

### マイルストーン
| # | 内容 | 実装 | 検証 | 工数/リスク |
|---|---|---|---|---|
| **V1** | リソース＋アドレッシング | VsmSystem: 物理アトラス(DSV/SRV)・ページテーブルbuf・フリーリスト。`Vsm.hlsli`: worldPos→(level, 仮想ページ, ページ内UV) 変換。CPU: レベル中心をページサイズ世界グリッドにスナップ | 単体（描画前）| 3-4日 / 中 |
| **V2** | 深度からページ要求(CS) | シーン深度走査CS: 各画素 worldPos→必要レベル(カメラ距離)→仮想ページ→要求ビットマスクに atomic マーク | 要求バッファがビュー内ページで埋まる | 3-4日 / 中 |
| **V3** | 物理割当＋ページ描画 | 要求済み未割当ページに物理タイル割当・ページテーブル更新／不要ページ返却。**描画**: 各割当ページごとに viewport=物理タイル、そのページの仮想サブ射影で影キャスタ描画（まずCPUループ版で正しさ優先、将来 GPU-driven/MS ルーティング） | アトラスにビュー内の深度が入る | **1-1.5週 / 高**（ページ毎射影・per-page描画）|
| **V4** | サンプリング差し替え | `TownShadow.hlsli` の `SampleSunShadowSoft` を VSM 参照へ: worldPos→level→仮想ページ→ページテーブル→物理UV→`SampleCmp`。**ページ境界PCFは隣接ページも参照** | per-pixel解像度・継ぎ目/エイリアス消滅 | 4-6日 / 中〜高 |
| **V5** | ページキャッシュ | ページ有効フラグ。太陽方向/レベル中心移動/ジオメトリ変化で無効化のみ再描画。町は静的→定常ほぼ再描画ゼロ | 定常で軽い（GPU時間）| 4-6日 / 中 |
| **V6** | ローカルライト＋ボリューメトリック | ClusterGrid のライト毎に同アトラスへ割当。Volumetric_CS がVSMをサンプル（神の光） | 多灯の影・フォグ光条 | 1-2週 / 中〜高 |

### 主要な落とし穴
- **ページ境界のPCF**: フィルタが隣ページへ跨る→ページテーブル経由で隣ページの物理UVへ切替（縁の黒線/破綻の主因）。
- **per-page 射影**: 各ページは仮想空間の一部だけ描画する専用 ortho サブ射影が必要（クリップマップ全体射影×ページのスケール/オフセット）。
- **フリーリスト**: 割当/返却の同期。まずCPU管理→後でGPU化。
- **atomic マーク**: `InterlockedOr` で要求ビット。
- **深度アトラス**: 割当ページのみクリア＋描画（全クリアは高コスト）。

### 着手順と成果地点
V1（リソース＋アドレッシング, 単体検証）→ V2（ページマーク）→ V3（割当＋描画=山場）→ **V4（サンプリング＝ここで見た目が変わる: 画素毎解像度・継ぎ目/エイリアス無しの影＝残ちらつき根絶）** → V5（キャッシュで実用速度）→ V6（多灯/大気）。**V1-V4 で約 3-4 週**。
